# Working modes

Recommend the lightest mode that fits. Default to B for anything distributed.

## Mode A: Quick skill (simple, single-purpose tasks)
SKILL.md, README.md, one example, basic validation report.

## Mode B: Professional skill (regular or commercial use)
SKILL.md; references/ for detail; templates/; examples/; tests/test-cases.md and tests/security-checklist.md; README.md, CHANGELOG.md, LICENSE; adapters/ only for platforms the user requested; marketplace listing.

## Mode C: Advanced skill system (complex, multi-tool workflows)
Everything in B plus: modular reference architecture, tool/integration docs, error-recovery procedures, security architecture notes, validation scripts where useful, extensive test scenarios, compatibility documentation.

## Rules for all modes
- Create only files that add real value. No empty, decorative, or duplicate files.
- Keep SKILL.md focused; push long material into references/.
- Reference every supporting file from SKILL.md with a note on when to read it.
